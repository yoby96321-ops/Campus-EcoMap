# Campus EcoMap｜中科大校園低碳美食地圖

哭哭夭夭 · v1.0.0 · 網頁前端程式設計期末專題

直接以 Chrome 或 Edge 開啟 **index.html**。餐廳搜尋、設施篩選、詳情與碳排比較均可離線操作。Google Maps 和來源查閱需連網。

## 開發與部署

1. 開發環境使用 Node.js 20 以上。執行 `npm test` 檢查語法及資料、公式、篩選、排序、導航。
2. 執行 `npm run build` 取得純靜態的 `dist/`。瀏覽器可直接開啟 `dist/index.html`。
3. 將 dist 的內容部署到靜態 HTTPS 主機。執行瀏覽器驗收、檢查外連，再由團隊核准切換正式版本。回滾時重新發布上一版已驗證的 dist。
4. GitHub Actions 工作流程會在推送、PR 或手動執行時檢查並產出 dist。瀏覽器回歸測試列於企業流程文件。

## 檔案

- `index.html` 頁面結構及教學說明。 `style.css` 響應式版面。
- `data.js` 店家、設施、係數與獨立計算邏輯。 `app.js` UI 互動。
- `assets/` 專題生成的餐點示意圖。含首頁餐點與八種分類的生成示意圖，圖片檔隨網站提供。
- `tests/` Node 測試。 `docs/` 專案治理、上線及展示文件。

## 數據說明

網站收錄 50 家餐飲店。店家詳情分別提供餐點、地址與設施資料。缺乏設施證據時，顯示到店規劃用的保守建議。

步行、單車 0，機車 0.09，汽車 0.20 kg CO₂e／人公里，屬教學示範值。計算為單程公里數乘 2，再乘係數。兩筆虛構店家只用於操作示範。

專題參考 [聯合國 SDG 13](https://sdgs.un.org/goals/goal13)。網站沒有登入、後端、分析追蹤或 API 金鑰。公開店家詳情內嵌 Google 地圖，可連網查看店家位置。地圖內點「顯示我的位置」並同意定位，會將座標交給 Google 在卡片內標示使用者所在位置，並提供一鍵切回店家位置。

可按餐點類型篩選。依距離排序時，步行路線待核對的店家排在最後。

## 餐點碳足跡

餐點示範配方採每項食材公斤數乘課堂係數，加上每份備製或烹調分攤用電。電力係數採 [114 年公用售電業電力排碳係數](https://serv.gcis.nat.gov.tw/biznetzero/Opendata/Index?id=da4d8c97c34e4b32b49c38b8cc61f8a9) 0.467 kg CO₂e／kWh。各配方可調整份數，配方自動帶入每份用電。餐點合計另加一人往返交通一次。範圍涵蓋所列食材上游及店內備製用電，瓦斯、包材、廢棄物及一般店務用電在範圍之外。

## 到店座位估算

網站依個別門市的照片、食記或公開評論帶入估算席數。選平日或週末與到店時間即可查看估算。模型的試算時段為 07:00–21:59，公開店家依各自的時段資料，課堂示範以午餐 11:30–13:30、晚餐 17:30–20:00 為尖峰（區間不含終點）。平日尖峰／非尖峰假設占用率為 60–90%／20–50%，週末為 75–98%／35–65%。區間以總席數乘剩餘比例，下限向下取整，上限向上取整。公開店家的總席數引用公開資料，剩餘席數由情境占用率估算。店家營業時間與即時候位請另外確認。詳見 [座位與尖峰資料](docs/座位與尖峰資料.md)。

以交通部資料所列三民路「國立臺中科技大學」站為固定起點，48 筆按 OpenStreetMap 步行路網計算去回程，其餘兩筆提供店名地圖搜尋。部分公開店家另附可查閱的價位或菜單來源。

## 位置推薦與餐點流程

使用裝置位置須由使用者按下推薦並同意瀏覽器定位。可使用三民校區作為替代起點。推薦以已收錄座標的店家計算直線距離，其餘列在後方；位置不儲存。卡片會滑動換位，系統偏好減少動態時直接切換。打開卡片可選店家已收錄的公開品項與份數，再進入製作及校園往返碳排估算。詳見 docs/位置推薦資料來源.md。

從店家卡片進入時預選該店已收錄品項及一份，確認後帶入配方用電與距離。交通碳排用校區步行去回程合計乘交通係數，未取得步行路線的店家仍可估算餐點製作碳排。在店家詳情內直接呈現計算結果。大眾運輸以燃油市區公車情境估算，採環境部《淨零綠生活行動指引》第 23 頁所列 0.078 kg CO₂e／人公里。定位前以校區步行往返距離估計，定位後使用 OpenStreetMap 道路往返距離估計。Google 地圖另外顯示大眾運輸路線。

店家菜單採各店獨立清單，49 家有公開品項資料，Hello 早餐店提供標明的早餐情境品項。每張卡可選平日或週末及到店時間，依公開席數、店內觀察或同類店型推估總席數與該時段剩位。部分公開品項來自舊菜單，供應以門市為準。

逐店查核狀態及來源請見 [菜單與設施查核](docs/菜單與設施查核.md)。

[50 筆步行與座位查核](docs/50店家步行與座位查核.md)包含各店地址證據、門牌點位、去程與回程距離及座位狀態。
