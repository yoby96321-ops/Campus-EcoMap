# Campus EcoMap v1.0.0 驗收紀錄

驗證日期 2026-11-25。以 Windows、Node.js 和 Microsoft Edge 執行。

| 驗證 | 結果與證據 |
|---|---|
| 語法、資料、公式、篩選與地圖 URL | npm test 通過 7 項 |
| 離線桌面與 320、390、768 px | Edge Playwright 自動化通過 |
| 無障礙操作抽測 | Enter 開詳情、Escape 關閉、焦點回到觸發按鈕 |
| 互動 | 50 筆公開資料、搜尋、設施交集、空結果、清除、四列交通比較 |
| 計算 | 0.50 km 示範目的地的機車 0.090、汽車 0.200 |
| 導航 | 驗證目的地參數；Google Maps 外部行程及實際距離需現場核對 |
| 瀏覽器例外 | 所測路徑內為 0 |
| 靜態建置 | npm run build 成功，dist 可作靜態部署 |
| 上線與正式簽核 | 本版以離線繳交為主。私人 Sites 同步未完成，店家實訪與團隊、課程方簽核待實際執行 |

重跑瀏覽器驗收可在有 Playwright 的環境執行 node tests/browser.cjs。可設定 ECOMAP_PLAYWRIGHT 為 Playwright 安裝路徑，ECOMAP_BROWSER 為 Edge/Chromium 執行檔。腳本將截圖寫入 qa。

餐點碳足跡驗收涵蓋食材與烹調用電分項、份數調整、餐點與交通合計、空白用電輸入。
