## 五分鐘操作

| 時段 | 操作 | 預期 |
|---|---|---|
| 0:00–0:40 | 開啟本機 index.html，介紹首頁與交通估算用途 | 首頁載入，可進入圖卡 |
| 0:40–1:40 | 看 49 筆公開圖卡，搜尋「豐仁冰」，打開詳情 | 一筆結果，地址與來源可見 |
| 1:40–2:30 | 清除搜尋，勾 Wi-Fi 與插座，再輸入「便當」 | 先剩泰丘鍋物，然後顯示空結果，按清除可恢復 |
| 2:30–3:20 | 切回公開資料，開一中豐仁冰詳情，向下查看內嵌地圖 | 地圖顯示店家位置。網路受限時仍可繼續本機操作 |
| 3:20–5:00 | 打開一中大本營，選餐點與份數，再切換交通方式 | 在卡片內查看餐點製作、往返交通及合計碳排，並確認地圖路線同步切換 |

展示前準備 Chrome 或 Edge、本機原始碼、簡報和可選的網路。正式計時以演練記錄補上。
